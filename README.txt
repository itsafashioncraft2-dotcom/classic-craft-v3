Classic Craft Tattoo Studio website (version 3)

Upload this whole folder to any static host (Netlify, Vercel, GoDaddy, Hostinger).
Open index.html first. Photos live in /assets.
Before launch: replace YOUR-DOMAIN.com in sitemap.xml and robots.txt, set the real domain in the canonical link inside index.html, add og-image.jpg for share previews, and swap assets/p1.jpg..p11.jpg with real studio photos (same filenames).
